# Triage Labels

As skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis
para as strings de label realmente usadas no rastreador de issues deste repo.

| Label em mattpocock/skills | Label no nosso rastreador | Significado                                |
| --------------------------- | -------------------------- | ------------------------------------------ |
| `needs-triage`               | `needs-triage`              | Mantenedor precisa avaliar essa issue      |
| `needs-info`                 | `needs-info`                | Aguardando mais informação do relator      |
| `ready-for-agent`            | `ready-for-agent`           | Totalmente especificado, pronto pra agente |
| `ready-for-human`            | `ready-for-human`           | Requer implementação humana                |
| `wontfix`                    | `wontfix`                   | Não será feito                             |

Quando uma skill mencionar um papel (ex.: "aplique a label de pronto-pra-agente"), use a string
de label correspondente desta tabela.

Edite a coluna da direita para bater com o vocabulário que você realmente usa.

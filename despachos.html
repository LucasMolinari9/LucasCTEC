Configurações da API

Obtenha em build.nvidia.com. A chave fica salva apenas no seu dispositivo.

Cole aqui a URL do seu proxy (ex.: https://orion-proxy.SEU-USUARIO.workers.dev). A NVIDIA não aceita chamadas diretas do navegador — veja a ajuda abaixo.

A API da NVIDIA bloqueia chamadas feitas direto do navegador (CORS), e mais ainda quando o app roda como arquivo local no celular. A correção é um proxy gratuito que você cria uma vez. Recomendado: Cloudflare Workers.

Passo a passo (uma vez só):
1. Crie conta grátis em dash.cloudflare.com (pode pelo celular).
2. Menu Workers & Pages → Create → Create Worker.
3. Clique em Edit code, apague tudo e cole o código abaixo.
4. Deploy. Vai aparecer uma URL tipo https://meu-worker.seu-usuario.workers.dev.
5. Cole essa URL no campo Endpoint aqui em cima e salve. Pronto.

Opcional (mais seguro): em Worker → Settings → Variables, crie a variável NVIDIA_API_KEY com sua chave. Assim a chave fica só na Cloudflare e não no celular.
